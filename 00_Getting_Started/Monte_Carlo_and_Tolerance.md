# Monte Carlo and Tolerance

Tolerance analysis studies the effect of bounded or statistically distributed variation in component or model parameters. The README must state the nominal value, tolerance distribution, random seed policy if relevant, number of runs, measured acceptance criterion, and interpretation limits.

A Monte Carlo histogram is evidence about the simulated model and distribution. It is not a guarantee about manufacturing yield unless the distribution, correlation assumptions, process corners, and sample size are justified. Keep the methodology in `11_Advanced_Analysis/03_Monte_Carlo/` and reference it from component-specific experiments.
